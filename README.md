# PEEPZ

A luxury, invite-only mobile-first content platform for creators and fans.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```

## Tech Stack
- Next.js 14
- React 18
- Tailwind CSS
- TypeScript
- Framer Motion
- shadcn/ui

## Project Structure
- `src/app/` — App directory (pages, layouts)
- `src/components/` — Reusable UI components
